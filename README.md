# 🐍 Snake Game

A classic Snake game built with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies. Fully responsive with keyboard, on-screen button, and touch swipe controls.

## 🎮 Live Demo

[Play it here](#) >> https://classicsnakegameweb.netlify.app

## ✨ Features

- Smooth canvas-based rendering
- Keyboard arrow key controls
- On-screen directional buttons (mobile-friendly)
- Touch swipe gestures for mobile play
- Score tracking with persistent high score (saved via `localStorage`)
- Responsive layout that adapts to any screen size
- Zero dependencies — pure HTML/CSS/JS

## 🛠️ Tech Stack

- **HTML5** — structure and canvas
- **CSS3** — styling, layout, and responsiveness
- **JavaScript (Vanilla)** — game logic and rendering

## 📂 Project Structure

```
snake-game/

├── style.css       # Styling and responsive design
├── script.js       # Game logic (movement, collisions, scoring)

### Deploy on Netlify

1. Push this repo to GitHub.
2. On [Netlify](https://netlify.com), click **Add new site → Import an existing project**.
3. Connect your GitHub repository.
4. Build settings: leave **build command** empty and set **publish directory** to `.` (root), since this is a static site.
5. Deploy — Netlify will give you a live URL.
